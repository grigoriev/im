# Fonts

JetBrains Mono NL 2.304 by JetBrains, from https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304
(`JetBrainsMono-2.304.zip`, SHA-256 `6f6376c6ed2960ea8a963cd7387ec9d76e3f629125bc33d1fdcd7eb7012f7bbf`).
License: SIL Open Font License 1.1, see `JetBrainsMono-LICENSE.txt`.

The PDF embeds these files. PDF/A forbids fonts that are not embedded. "NL" is the variant without code
ligatures, so text such as `->` prints as typed. The web app loads the same font from npm.
